# Tier 1: The Tell Protocol

*The goal of Tier 1 is to understand how exchanges become records.*

Each exchange is captured, sorted and hashed. The record holds only hashes, types, timestamps and references, never stories or identities (JFA line 7), and nothing is erased (line 6).
